# Scope gates · Prototype ≠ MVP

## B00 implemented
- Only Kai; temporary procedural sprites (4 facing still images, no authored run animation), two enemies, deterministic seeded waves, obstacles, damage/XP/8 upgrades, Q, dash, early F, pause/settings/death/retry and local best score.

## Deliberately missing, not bugs masquerading as completed features
- Original approved pixel character art; idle/run/attack/dash/hurt/death frame animation and Blender source.
- Ren/Sora gameplay and their form sets, full Kai Form II/III, complete ability slots E/R, sophisticated weapon slots and relic synergies.
- Seven enemy behaviors/elite/bosses, procedural regions and all 18-minute pacing, persistent challenge/unlock board, event system.
- Game audio, rebindable keys, full accessibility suite and full performance load testing.
- Local mid-run save/resume, cloud sync, native desktop distribution.
