# Game Vision · KYNTRAZE: FRACTURE RUSH

The full master handoff attached by the game director is the authoritative vision; this file summarizes only the **B00-active interpretation**.

- Genre: original high-readability pixel-art 2D faux-depth horde survival with auto-target attacks and optional dash/manual techniques, **not** a Hades-style manual room brawler.
- Primary platform: Windows browser, 2D collisions, single player, offline static build.
- Cast: Kai, Ren, Sora, each with Base + Form I/II/III. Only Kai Base and an early functional Flarebound prototype ship in B00.
- Signature: progressively escalating enemy density and builds, Drive to manually activate earned forms, responsive survival positioning.
- World: Gloam Circuit is an original fractured-transit landscape. This batch uses debug floor tiles/columns, not finalized environment art.
- Production: Codex creates approved original sprite art and scoped code batches; Claude Code rigs/animates with Blender; ChatGPT reviews source and creates one batch prompt at a time. The user approves each milestone.
- No purchases, cloud account, auto pushes or deployment.
