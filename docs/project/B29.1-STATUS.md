# B29.1 status: cinematic menu art direction

Baseline: B29 (`010afa1`). Review screenshots: `docs/project/b29-1-review/` (960x540 and 640x360 for every screen; 1920x1080 for the main set). New art provenance and prompts: `art/menu-b29-1/`.

## By screen
- **Shared kit**: larger type (body 10.5-14 px at 640x360 / 960x540 targets), distinct states: selected (accent + check), keyboard/pad focus (cyan outline), hover (subtle), inspected (teal), owned/equipped, locked, disabled. A flat `b29-quiet` secondary button now matches the primary CTA.
- **Title**: obsolete "RELEASE CANDIDATE B20" chip replaced by the real build version (from `package.json` via a Vite define); secondary buttons share the CTA family; footer simplified.
- **Nexus**: kept as is; transformations now counted consistently (not base) for every hero ("3/3 forms" = transformations), selected check moved into the name plate (no floating mark), other heroes less dimmed, pending deploy timer cleared on leave.
- **Hero Select (flagship)**: authored hero-chamber backdrop; large real animated sprite of the inspected appearance on its plinth with aura; per-form selector (Base, Flarebound, Cometheart, Stillfire Apex / Ascendant / Sovereign / Riftbound, Voidheart) with real unlock wording and silhouette teaser for locked forms; preview-only (never touches saves, Drive or the run); an Abilities tab built from the real content tables (auto, Q, E, R, V, Overdrive, flight, dash with icons, names, effects, bindings); run setup tab and one DEPLOY. Invented power/reach bars removed.
- **Mode Select**: mission observatory backdrop; seven authored round emblems; poster detail (length, players, rewards, options); Solo / Local co-op / Online co-op with plain subtitles; partner picker only when local co-op is active; no "needs a server" copy.
- **Arena Select**: each arena shows its own generated scenic illustration (from the real in-game card art); factual hazard rhythm, ground and run availability (arbitrary meters removed); expedition-only realms are inspected first and switch the mode only on "Use this arena" with the consequence stated.
- **Armory / Contracts / Records**: relic vault, pact altar and record hall backdrops; larger item cards; a real detail pedestal with big icon and an explicit Buy / Equip / Unequip button (moving focus never buys); contracts show selected vs inspected separately, rule, reward, requirement and an explicit Select button; Records no longer shows Kai-only form text above the roster.
- **Archives**: library backdrop, readable type across all six sections (Story, Mastery, Outfits & Crests, Codex, Records, Boards), unchanged data and actions.
- **Online lobby**: alliance chamber with two hero stations (you left, partner right, empty seat as an invitation), friendly 3-step flow (say hello, host or join, ready up), server address moved to an Advanced disclosure (official server stays default), plain-language errors, copy-code button. Verified against a real local server with two live clients (see below).
- **Settings**: unchanged.
- **Controller**: pad root now recognises every menu screen (done in B29), re-verified.

## Generated vs reused
Generated with the Codex ImageGen bridge (`art/menu-b29-1/`): hero chamber, mission observatory, relic vault, contract altar, archive library, alliance chamber (6 backdrops), a 7-emblem mode sheet (cut and keyed to alpha), 4 arena scenes (reference: the real arena cards). Reused: hero idle sprite sheets (all forms), Nexus plinths and portal art, existing icons and crests.

## Verified
`tsc --noEmit`, `npm run build`, full vitest (769 pass incl. new `b29-1-menus.test.ts`: forms, kits, icons and art exist), e2e `nexus`, `b22-ui`, `b22-modes`, `b22-coop` (two older specs updated: partner picker now needs "Local co-op" first). Headless sweep of every screen and Archive tab at 960x540 and 640x360 (0 overflow, 0 console errors, 0 failed requests) and most at 1920x1080. Simulated pad: D-pad focus and B back on Hero, Mode, Online, Armory, Archives, Contracts. Live lobby: two real clients on a local server, host/join by code, hero switching, ready flow, room view screenshots.

## Not verified / limits
Motion at real speed, audio, a physical controller; the 1920x1080 sweep stalled on a few clicks under software rendering (screenshots exist for most screens); Story and Records tabs at 1920; hero previews are idle loops only (no action clips); base-only sprite scale per hero is approximate on the plinth; dark overlays on list-heavy screens (Archives) keep the art subdued for legibility.
