# B26 - Ren: Crimson Ascendant combat and Primal Overdrive

Sections are appended per stage. This file starts with the **Code stage** (simulation, HUD text, audio recipes, compatibility). The art stage (Crimson Nine-Tailed Fox ImageGen assets, Blender poses, renderer wiring) is tracked separately and is NOT covered here.

## Code stage

### What exists (simulation, deterministic, authoritative)
- `src/content/renCombat.ts`: every number of the form-only kit. `src/sim/RenCombat.ts`: the kit. Base Ren (Hammer Chain, Crimson Break, Meteor Rush, Bloodstar Impact) is untouched; the transformed state switches at `hero === 'ren' && form >= 1` inside `HeroSystem` (`renAuto`, `heroActivateQ`, `heroStartE`, `heroStartR`).
- **Crimson Fury** (auto): four beats jab / kick / hook / rising uppercut (finisher sweeps 92 px, capped, bosses hurt but never thrown). Close range only: nobody within 96 px = no swing and no far hit. One `ren_auto` event per beat (n: beat bits 0-1, finisher 32, right hand 64, hit count from bit 8, Overdrive bit 1<<14).
- **Infernal Cyclone** (Q, 8 s): 0.18 s windup, 0.65 s spin, 4 bounded contact ticks, collision-aware pull of ordinary enemies (radius 145 x qRadius), outward release at 175 x qRadius (+stagger, push). Bosses / parts / shielded foes are never pulled or pushed.
- **Scarlet Rampage** (E, 10 s): nearest valid enemy in a forward cone (<= 300, wall-free line, ties by id). Ordinary target: real grab, 0.4 s collision-validated drive (target follows Ren, stops at the first wall), slam AoE at the real destination. Boss / part / shielded: grounded shoulder strike + splash, no relocation. Nothing in front: bounded forward rush + ground impact, no fake grab.
- **Crimson Catastrophe** (R, 20 s): committed ground point (reuses Bloodstar's `pickGround`), 0.4 s telegraph, three alternating fists (L, R, L; r 95) then a converging final (r 175). Per-event damage once via `damageEnemy`, capped at 14 targets per hit.
- **Crimson Nova Fist** (V, 45 s, hold): `nova_fist` HeroCast. Tiers .35 / .9 / 1.6 s, 2.3 s cap, min hold .08 s; unreleased charge cancels free on hit, dash, form change, ultimate, death, cinema, `sigAbort`; a real release spends the cooldown even on a miss. Collision-safe lunge, contact required: a miss emits `ren_v_miss` and never explodes; a blocked hit emits `ren_v_block`. Tier 0-1 burst, tier 2 burst + two spiral pulses, tier 3 eruption + delayed outer ring. Cooldown ticks in base and form.
- **Primal Overdrive** (G): meter 0-100, +1.4 per damaging hit, +3 per kill, **rate-limited to 4 meter-hits per 0.25 s window** (`hx.odWin`), nothing fills during Overdrive, 10 s, +25% damage (applied once in `damageEnemy`, shared with Kai), +8% speed, 0.88 auto period. Ends with the form, death or a cinematic. No separate beast HP or AI.
- **Skybreaker** (hold dash >= 0.28 s): speed x1.35, extra Drive drain 6/s on top of the form's, min Drive 12, 5 s cap, 3.5 s cooldown, one bounded landing slam only after >= 0.5 s of flight, no hazard or collision change.
- Shared plumbing generalised for Ren, Kai code paths unchanged: `kaiCombatInput`, `odGain`, `sigCharge`, `damageEnemy` Overdrive multiplier, `MovementSystem` speed, `HeroAct` union, `AbilityEventKind` union. Co-op: all state is per fighter (`Fighter` fields and `hx`, swapped by `CoopSystem`).
- Online: no protocol change was needed (`sig`, `sigHeld`, `sigAbort`, `od`, `flyHeld` already travel; the new acts, events and fields ride the existing `hx.act` / `abilityEvents` / `player` snapshot).

## Art stage (ImageGen, Crimson Nine-Tailed Fox + Ren FX)

Generated through the Codex ImageGen bridge (same audited wrapper as B25), reference style `public/art/fx/kai-form2/aura_a.png`. Sources, prompts (`<name>-prompt.txt`), `sheets.py` (all prompts), `run.py` and `PROVENANCE.md` are in `art/fx-b26/`; `scripts/b26-cut.py` cuts them (connected components, masked per sprite, palette-quantised to 160 colours) into `public/art/fx/ren-fox/<name><0-3>.png` + `manifest.json` (frames, native sizes, anchor hints, source sheet). All runtime frames are RGB on black, drawn with ADD blend. Skill icons: `public/ui/icons/ren_cf_{fury,cyclone,rampage,catastrophe,nova_fist,overdrive}.png` (96 px, luma alpha).

Beast: `head_side` (closed / snarl / roar / breath), `head_front`, `head_back`, `body` (shoulder / torso / haunch / crouch wrap segments), `paw_only` (right-facing strike sequence), `paw_b` (downward slam), `tails_only` + `tails_only_stream` (isolated nine-tail fans, root at right), `tails_rest` + `tails_stream` (whole-beast side loops), `tails_flare` (front, gather/snap/open/fan), `activation`, `dissolve`, `ground_ring`. FX: `cyclone_arc`, `cyclone_crack`, `rampage_dust`, `rampage_trail`, `fist_l`, `fist_r`, `cat_debris`, `cat_shock`, `nova_orb` (tiers 1-3 + overcharge), `nova_spiral`, `nova_core`, `nova_ring`, `fist_trail`, `flight_ring` (paw print), `flight_fan`, `wisps`, `wisp_arc`.

Honest quality notes: every sheet was viewed at sheet scale and a contact montage of the cuts was checked; nothing has been seen in-game, at real scale or in motion. Weak / limits: `tails_only` four frames are nearly identical (animate by procedural sway, not by frame flipping); `body` segments are abstract (flame-fur shapes, read best behind a fighter, not as a standalone creature); `paw_a` / first `head_side` / `tails_*` sheets showed the whole fox and were kept only as full-beast references (`head_side_v2`, `tails_only*`, `paw_only` replaced them for layering); `fist_r` frame 0 touched the sheet edge so `giant_fist_r_v2` was used; `rampage_dust` is thin and ground-aligned; `icons` tile 3 (Rampage) is somewhat ambiguous. No Blender poses, no body-layer anchor testing and no integration were done in this stage. Not Kai art recoloured: all sheets are new crimson/white-hot designs.

## Render stage (fox controller, ren_* FX, presence, icons, card text)

**Code:** `src/game/render/renFox.ts` (`RenFox`, one instance per Ren fighter, created in `EntityRenderer.syncHero`, destroyed with it; camera shake only for the local fighter). Textures `rf-<set><0-3>` (28 sets, 112 keys, bounded) preloaded in `BootScene`; a missing file leaves that layer off.
- **Fox (Overdrive only):** east/west = the whole `tails_rest` / `tails_stream` beast behind Ren (chest behind him, head above and ahead of the shoulders, nine tails), lagging position, lean into movement, breathing, crouch while V charges, pop on release; south = `tails_flare` front beast (gather / open frames follow V and lunge); north = `head_back` over the head plus two swaying `tails_only` fans rising behind. Activation (`activation` + ground ring + shake, ~0.85 s), expiry (`dissolve`), strike surges (`head_side` lunges to the real target) and forepaw (`paw_only`, larger upward paw on the finisher) from real `ren_auto` / Q / E / R / V events. All fox layers sit behind Ren (depth 9.0-9.05); only brief paw / fist strikes are in front. Size about 1.9 hero heights.
- **Event FX:** Cyclone spinning arcs while the cast runs + tick arcs, release arc / crack / ring; Rampage dust, momentum trail only while actually moving in the drive, slam crack / dust / debris / (Overdrive) downward paw; Catastrophe mark ring, left / right fists per hit, converging pair + shock + debris on the final; Nova Fist orb in the real hand (frame by tier) with counter-rotating spiral, tier rings, fist trail, core / spiral / ring on contact, grey rings for block / miss; flight ring at liftoff, tail fan while airborne, slam crack / shock / debris on the dive landing. Reduced Effects drops debris, trails, arcs and shake.
- **Presence:** ground pressure ring pulses while running (not in crowds / reduced) and on dash, shoulder wisps (calm idle, brighter when casting), a `wisp_arc` ribbon at the striking hand. The energy silhouette and animated stroke are the existing Ren aura glow filter and `crimson_ascendant` contour (no second silhouette added: it only made the sprite busier). Afterimages: the existing capped `ghostTrail` now also fires for Scarlet Rampage and flight.
- **HUD:** slots use `ren_cf_cyclone / rampage / catastrophe / nova_fist / overdrive`; those icons are full-colour art, so `.slot.art` in `kit.css` draws them as images instead of white masks (first smoke showed solid white squares; fixed).
- **Card text:** `REN_FORM_NOTE` (branches) and `REN_FORM_LEGEND` (legendaries) add an "Ascendant: ..." line to the offer cards in `ascView.ts`, written to match what `BranchSystem` really does (every 3rd Cyclone contact, max 3 relay strikes at 60%, final fist only for the Catastrophe branches, etc.). The Archives list still shows base text.
