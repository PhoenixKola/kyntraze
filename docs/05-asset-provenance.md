# Asset provenance

All `public/art/placeholders/*.png` are locally rendered geometric raster debugging shapes using Pillow; original source script `art-source/create-placeholders.py`. They are not photoreal 3D, ImageGen-created, user-approved, fully animated or commercially finalized. No externally hosted game textures.

A Codex/Claude replacement should preserve old working identifiers until the approved atlas loader and manifest validator are integrated. Every new asset should record source master, generator/tool/version, edits, rights/license and owner acceptance state.
